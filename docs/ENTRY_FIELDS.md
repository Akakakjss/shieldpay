# ShieldPay account-entry checklist

This is an entrant checklist, not part of the public product story. No Devpost account draft or final entry has been submitted by preparing these files.

## Fields

- Project name: **ShieldPay**.
- Tagline: **Turn scattered PayPal dispute records into a response you can check before you send.**
- Story: use the narrative sections of [DEVPOST_COPY.md](DEVPOST_COPY.md), including its concise prototype-status section. The longer [COMPLETE_SUMMARY.md](COMPLETE_SUMMARY.md) is an engineering handoff, not the pitch.
- Public source: https://github.com/Akakakjss/shieldpay
- License: MIT for original code; dependency/model notices are separate.
- Functional access: use the repository's complete local run instructions. There is currently no hosted URL; do not enter a localhost address as a public demo. Complete setup instructions are allowed instead of hosting.[1]
- Video: upload your own demonstration to YouTube as **public** and add the actual URL. Keep it below three minutes, show the working application, review rights, and check playback while logged out.[1] The assistant's local draft is not the chosen submission video.
- Screenshots: use original assets from [assets/](assets/), preserving synthetic-data labels.
- Entrant/team: enter actual contributors, confirm eligibility, ownership, registration and required rights. Do not copy synthetic customer names into contributor fields.
- Tools: use the implemented stack listed in the story. Runtime AI is local ONNX embeddings; Hermes/GPT assisted development. Do not claim AG Studio, Studio Agent Framework, PayPal Agent Toolkit, a Render deployment or a runtime GPT integration.

## Sponsor tracks

AG Grid Community is implemented. The official rules allow eligible submissions using any AG Grid tools to compete for that sponsor prize; winning is not established by using the library.[1] The sponsor's guidance emphasizes custom widgets, theming, layout and Studio Agent Framework.[11]

Render configuration alone is not a deployed service. The Render awards listed in the rules are **Render credits**, not cash.[1] Do not select or describe a Render deployment as completed until it has actually been deployed and verified.

## Before submitting

1. Keep the synthetic/simulated labels and unverified-upload status consistent across the video, story and screenshots.
2. If an authorized sandbox evidence upload is completed later, update the story only to what the exact remote readback proves. A successful test upload is not a dispute win or verified carrier delivery.
3. Review all required Devpost fields in your account, save, submit and verify the actual confirmation. Prepared text and published source do not submit an entry.
4. Submit before **November 12, 2026, noon Pacific / 3 p.m. Eastern** and retain functional judging access through **December 15, 2026, 8 a.m. Pacific**.[1]
